## 文档约定

- **文档即契约**:设计在写代码前定稿,写代码时同步更新
- **同 PR 评审**:文档与代码一起改,不允许「代码先上、文档后补」
- **不写失效引用**:引用其他文档时用相对链接,CI 校验链接有效性
- **决策要留痕**:重要技术决策追加到 [04-decisions.md](./04-decisions.md),格式为 ADR
